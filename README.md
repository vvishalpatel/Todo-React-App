# 📝 To-Do List App

A simple and clean To-Do List application built with **React** and styled using **Tailwind CSS**. This app helps you manage your daily tasks by allowing you to add, delete, and mark tasks as complete or incomplete. All tasks are stored in the browser's **localStorage** so your list persists even after closing the browser.


## 🚀 Features

- ✅ Add new tasks
- ❌ Delete tasks
- 🔄 Toggle task completion status
- 💾 Store tasks in `localStorage`
- 🎨 Beautiful and responsive UI using Tailwind CSS
